# Мобильные взаимодействия

## Семейный альбом

На экранах уже 900 CSS-пикселей заголовок галереи сокращается до «Семейный альбом». Длинная поясняющая подпись и служебная метка скрываются, а переключатели группировки остаются сразу под заголовком. При просмотре альбома конкретного человека в заголовке остаётся только его имя и фамилия.

## Родство долгим нажатием

На телефоне долгое нажатие на карточку человека в древе (около половины секунды) включает существующий режим «Родство» и выбирает этого человека первым участником. Если один человек уже выбран для родства, долгое нажатие на другого добавляет второго.

Жест работает только для основного touch-указателя на экранах уже 900 CSS-пикселей. Движение пальца больше 12 пикселей отменяет long-press, чтобы панорамирование дерева не превращалось в случайный выбор. После срабатывания long-press следующий синтетический click подавляется.

Пока пара не выбрана, мобильная нижняя панель показывает только два слота выбора людей. Десктопная подсказка про Shift в этом мобильном состоянии скрыта. После выбора двух людей отображается обычный результат анализа родства.
