# Повторная проверка расстановки — 2 ноября 2026

Проверен текущий алгоритм `unionGeometry` с продуктивными размерами карточек,
поколениями, подбором вариантов и маршрутизацией. Данные синтетические:
рабочий архив и его фотографии не использовались. Геометрия и версия кеша
не изменялись.

Во всех 27 графах координаты карточек и точек маршрутов конечны. На трёх
больших графах диагональных сегментов нет. Это проверка корректности на
выбранных примерах, а не доказательство отсутствия пересечений для любой
семьи. Переплетённые связи между разными ветвями всё ещё пересекаются;
алгоритм выбирает ограниченный набор вариантов и не гарантирует оптимум.

Полное измерение больших примеров заняло соответственно 7,8 / 7,1 / 13,3 с
в локальном Node 24.22.2 на Windows, включая оценку качества. Во время части
замеров параллельно шли браузерные проверки; это не изолированный benchmark
производительности и не время открытия рабочего архива. Для интерактивного
открытия большой архив по умолчанию использует фрагменты.

Воспроизведение в PowerShell после настройки Node:

```powershell
$env:DREVO_LAYOUT_PRODUCTION_SCAN = '1'
$env:DREVO_LAYOUT_LARGE = '1'
$env:DREVO_LAYOUT_LIMIT = '24'
node --experimental-strip-types tests/layout-benchmark.mjs
Remove-Item Env:DREVO_LAYOUT_PRODUCTION_SCAN, Env:DREVO_LAYOUT_LARGE, Env:DREVO_LAYOUT_LIMIT
$env:DREVO_LAYOUT_SCALE_SCAN = '1'
foreach ($layoutCase in @(4, 7, 14)) {
  $env:DREVO_LAYOUT_CASE = [string]$layoutCase
  node --experimental-strip-types tests/layout-benchmark.mjs
}
Remove-Item Env:DREVO_LAYOUT_SCALE_SCAN, Env:DREVO_LAYOUT_CASE
```

Отдельно проверяются инкрементальная геометрия, добавление супруга и предка,
обычное и обратное направление времени, ручное размещение, поколения и
передача прошлой геометрии настоящему собранному Worker. Браузерные сценарии
`tree-layout-cache.spec.ts` проверяют сохранение старых позиций после правок,
расчёт после изменения дат/прав и повторное открытие сохранённой геометрии.

Локальная проверка завершилась без ошибок: 1725 unit-тестов, 10 тестов
собранного Worker, typecheck, lint и build. В трёх целевых браузерных прогонах
прошли 70 сценариев, 20 пропущены по платформе. Включены камера, кеш раскладки,
изменение семьи, жесты, reduced motion и поиск документов. Мобильный viewport
эмулирован в Chromium; физический телефон не проверялся. Новая проверка
PostgreSQL добавлена в integration-набор, локально PostgreSQL не запускался.
