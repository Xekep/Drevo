# Публикация людей в поиске

Администратор открывает контекстное меню карточки человека и выбирает «Публикация в поиске». Опубликовать можно только человека с указанной смертью или подтверждённым статусом умершего. Публикация требует отдельного нажатия «Опубликовать в поиске»; создание временной ссылки не публикует карточку. Снять публикацию можно там же. Прямая ссылка после этого сразу перестаёт открываться. Если статус человека изменится на живущего или неизвестный, сервер перестанет показывать ранее опубликованную карточку.

Вошедшие пользователи ищут опубликованных людей на `/discover` даже без доступа к древу. Поиск и карточка показывают только ФИО, годы рождения и смерти, места рождения и смерти. Связи, фото, биография, документы, заметки и источники остаются закрытыми. Запросы ограничены по частоте; анонимный поиск недоступен.

Пока поиск выполняется в пределах текущего архива. Для поиска по всем архивам после их серверной изоляции потребуется отдельный межархивный индекс. SQLite создаёт таблицу `published_people` при обновлении схемы; PostgreSQL применяет `ops/postgres/019_published_people.sql` при запуске.
