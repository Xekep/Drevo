# Материалы полного UI аудита Drevo

Снимки и измерения относятся к синтетическому локальному E2E-серверу,
исходникам `60783787879d0e1ddd64207fc6d019ff38286da8` и production dist этого состояния.
Не содержат пользовательские архивы и секреты.

Основной отчёт: [UI аудит всего проекта](../../ui-audit-full-2026-10-10.md).

- `overview.json`: 74 обзорных состояния, computed контраст, итог 44 E2E.
- `deep.json`: разделы управления древом и подтверждённая потеря черновика источника.
- `controls.json`: формы платформы и потеря SMTP-черновика; промежуточный keyboard
  probe выбрал видимый option и сам по себе не подтверждает UIF-03.
- `media.json`: окончательная проверка невидимого шестого option, Ctrl+click,
  поиск людей для документа и медиа. Снимок `fan-390` из этого первого прохода
  закрыт профилем; итоговый открытый веер — `fan-final-390.png`.
- `final-check.json`: потеря нового документа при обычной навигации. Позднейшие
  шаги этого probe не завершены, их результаты не утверждаются как browser evidence.
- `reader-resize-check.json` и `reader-resize-empty-0.png`: два повтора исчезновения
  страниц после responsive-переходов, с ожиданием 3,5 секунды.
- `reader-final-390.png`: прямое открытие ридера работает; это не противоречит
  сбою после нескольких resize.
- Остальные PNG: читаемость хронологии, каталог людей, редактор, источник,
  экспорт и настройки email.

Воспроизведение PDF на отдельном синтетическом сервере:

```powershell
$env:DREVO_E2E_PORT='4197'
node --experimental-strip-types tests/e2e-server.ts
```

В другом терминале из корня репозитория:

```powershell
node docs/benchmarks/ui-review-full-20261010/media-probe.cjs
node docs/benchmarks/ui-review-full-20261010/reader-resize-check.cjs
```

Скрипты используют Chrome из стандартного Windows-пути и только loopback:4197.
Первый загружает синтетический трёхстраничный PDF в тестовую БД. Второй открывает
его и сохраняет состояния после resize. Скрипты не предназначены для production.
Для чистого завершения тестового сервера отправить Ctrl+C.
