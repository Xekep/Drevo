# Документация

Документы разделены по читателю:

- **[Для инженера-программиста](engineering/README.md)** — устройство проекта,
  разработка, API, установка, эксплуатация и работа с данными.
- **[Для агента](agent/README.md)** — память между сессиями, история решений,
  аудиты, эксперименты и исходные замеры.

Актуальное поведение определяется кодом и тестами. Датированные отчёты
сохраняют результаты конкретной проверки и не заменяют рабочую документацию.
