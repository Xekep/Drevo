# Какие связи вводить

В форме две группы:

| Группа                         | Ручной ввод                                                  |
| ------------------------------ | ------------------------------------------------------------ |
| Семья                          | Кровный родитель, супруг / супруга, приёмный родитель        |
| Крёстные, опека и другие связи | Крёстный родитель, кормилица, названые брат / сестра, опекун |

Первый выбранный человек является указанным родственником второго. Например, для матери и дочери выберите мать первой, связь «Кровный родитель», дочь второй.

Брат, сестра, дед, бабушка, внуки, дяди, племянники и двоюродные родственники вычисляются из родителей. Свёкор, свекровь, тесть, тёща, деверь, шурин, золовка, свояченица, зять, невестка, сваты и другие связи через брак вычисляются из графа. Их не нужно дублировать отдельными рёбрами.

Полнородные, единокровные, единоутробные и сводные братья и сёстры различаются по известным родителям. Если сведений недостаточно, программа показывает осторожное пояснение. Не создавайте вымышленных родителей ради желаемого названия связи.

Синонимы и мужские/женские варианты не занимают отдельные пункты списка. Обобщения «родня», «предок», «потомок», «дальний родственник» не определяют конкретное ребро графа.

Вдова/вдовец — состояние человека, а бывший супруг и партнёр требуют отдельных сведений о статусе и периоде отношений. Текущая модель хранит только факт брака без его истории; эти статусы пока можно описать в заметке. Приёмное родительство и опека хранятся отдельно от кровных родителей; юридические подробности указывайте в примечании и источнике.
