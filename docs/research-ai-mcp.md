# ИИ-исследователь и MCP

Drevo использует единый набор read-only Research Tools для встроенного веб-ассистента и внешних MCP-клиентов. Инструменты находятся в `src/domain/research-tools.ts` и работают только с переданной проекцией `Family`.

## Yandex AI Studio

Встроенный веб-ассистент вызывает только серверный endpoint `POST /api/ai/chat`. API-ключ не передаётся браузеру.

Переменные окружения:

```
YANDEX_AI_API_KEY=<API key>
YANDEX_AI_FOLDER_ID=<folder id>
YANDEX_AI_MODEL=yandexgpt/rc
```

`YANDEX_AI_MODEL` можно задать полным URI вида `gpt://<folder>/...`. Для обычного имени модели сервер формирует URI из `YANDEX_AI_FOLDER_ID`. Необязательный `YANDEX_AI_BASE_URL` предназначен для совместимого endpoint и по умолчанию равен `https://ai.api.cloud.yandex.net/v1`.

Ассистент доступен только пользователю с правом чтения архива. Для пользователя с ограничением `common_ancestors` инструменты получают ту же проекцию семейных данных, что и обычный интерфейс.

Модель не получает фотографии, face descriptors, аккаунты и административные данные. Источники не входят в обычные tree-tools и доступны отдельным инструментом.

## MCP

Endpoint: `POST /mcp`.

Авторизация:

```
Authorization: Bearer drevo_mcp_...
Content-Type: application/json
```

Поддержан stateless набор MCP/JSON-RPC методов:

- `initialize`;
- `notifications/*`;
- `ping`;
- `tools/list`;
- `tools/call`.

Токены создаются администратором в разделе **MCP и ИИ**. Доступные scopes:

- `tree:read` — люди, семья, предки, потомки и поиск;
- `sources:read` — источники;
- `analysis:read` — родство, пробелы, противоречия и статистика.

Секрет выдаётся один раз. В базе хранится SHA-256 токена, имя, scopes, срок действия, автор выдачи и время последнего использования. Отзыв начинает действовать со следующего запроса.

MCP специально остаётся read-only. Записывающие операции будут добавляться только через отдельный слой атомарных application-команд и сначала в форме предложений, требующих подтверждения человеком.
