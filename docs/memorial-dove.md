# Рисованный белый голубь

[`src/assets/memorial-dove-drawn.png`](../src/assets/memorial-dove-drawn.png) — PNG RGBA 1254 × 1254, около 972 КиБ. Подготовлен встроенным **image_gen** 9 сентября 2026 года по предоставленному пользователем образцу рисованных белых голубей. Оригинальный альфа-канал сохранён; файл не перекрашивался и не обрезался. Трёхмерная модель и Three.js удалены из проекта.

Птица сразу сидит справа над верхней строкой ФИО — фамилией — в карточке умершего. SVG-контейнер — 64 px. Птица расположена абсолютно и не добавляет отступов между фото и ФИО или между строками; размер текста и переносы остаются обычными. При первом наведении мыши на фамилию проигрываются восемь фаз взмаха с частотой около 14 кадров/с, три цикла за 1,68 секунды. Это покадровая рисованная анимация; сглаживается траектория перемещения. Положение рисунков совмещено по голове, а области атласа показаны через вложенный SVG в `components/memorial-name.tsx`. Атлас загружается одним файлом; на странице одновременно отображается одна поза. Таймер работает только во время взлёта, очищается по окончании и при закрытии карточки. Новое наведение не возвращает птицу.

На телефоне, при отсутствии мыши и при `prefers-reduced-motion: reduce` остаётся сидящая поза. Изменение настройки движения останавливает анимацию. Голубь не перехватывает клики, подпись для средств доступности — «Светлая память». Возраст не служит основанием считать человека умершим: нужна записанная дата или место смерти.
