## Что найдено и исправлено

- Язык блока `xychart` отображался кодом; поддержан и для сохранённых ответов.
- Многословные подписи оси без кавычек разбивались по пробелам. Пробелы перед кавычками также могли оставлять сами кавычки в подписях.
- Поле `averageLifespan` старой сводки означало среднее только среди умерших взрослых, не сообщая об ограничении модели. Добавлены метаданные и отдельный аналитический инструмент с явной выборкой.
- Модель цитировала `half_or_unknown`. Для MCP код сохранён; в ответе инструмента для модели остаётся человеческое описание. Старые служебные упоминания дополнительно обрабатываются при формировании ответа.
- Читателю модель предлагала кнопку редактирования, которой у него нет. Запросы изменения от читателя теперь обрабатываются до обращения к модели.

## Повторение

Указать `YANDEX_AI_API_KEY`, `YANDEX_AI_FOLDER_ID`, `YANDEX_AI_MODEL` в окружении, затем из корня репозитория:

```sh
node --experimental-strip-types ops/check-ai-research.ts
node --experimental-strip-types ops/check-ai-research.ts --scoped
```

Это платные запросы к настроенному провайдеру. Скрипт создаёт отдельную временную БД, удаляет её после завершения и сохраняет отчёты в игнорируемом `work/ai-eval-admin.json` / `work/ai-eval-reader.json`. Можно указать `DREVO_AI_EVAL_REPORT`. В отчёте — синтетические ответы, вызовы инструментов и результат парсинга диаграмм; секреты не сохраняются. Сценарии предназначены для проверки человеком, завершение скрипта само по себе не означает правильности всех текстовых ответов.

Автоматические регрессии: `lifespan-statistics.test.ts`, `ai-research-http.test.ts`, `research-graph.spec.ts`, `research-chat-selection.spec.ts`.

Не удалось проверить в этом прогоне: распознавание содержимого настоящих семейных фотографий реальной моделью, длинные многодневные диалоги и все другие модели провайдера. Рендер диаграмм, остановка, параллельные чаты и прозрачность окна проверялись браузерными автотестами отдельно.
