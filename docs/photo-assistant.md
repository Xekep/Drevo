# Фотографии и разметка людей

Нажатие на снимок открывает **просмотр**. На компьютере рамка с именем появляется только при наведении на отмеченного человека или клавиатурном фокусе. На телефоне отметки включаются кнопкой **«Показать отметки»**. Список людей и переходы в карточки доступны рядом со снимком.

Кнопка **«Редактировать»** на компьютере открывает разметку, создание человека, изменение метаданных и доступное по роли удаление. Здесь рамки всегда видны. При первом входе в редактирование неразмеченного снимка запускается поиск лиц; кнопка **«Найти лица»** повторяет его. Приложение предлагает рамки; имя выбирает человек.

1. Выберите «Добавить → Фотографию». Перетащите снимок в окно или выберите файл, проверьте предпросмотр и заполните известные место, год и событие. Нажмите «Сохранить и отметить людей».
2. Выберите предложенную рамку или нарисуйте свою.
3. Начните вводить ФИО. Через 250 мс сервер подгрузит до 20 совпадений с годами жизни и фамилией при рождении. Выберите человека и сохраните отметку. Поиск поддерживает стрелки, Enter и Escape; устаревшие запросы отменяются.

После загрузки через «Сохранить и отметить людей» сразу открывается редактирование. В этом режиме можно создать человека: после сохранения карточки вы вернётесь к фото. Численные настройки рамки раскрываются через «Уточнить рамку». Данные снимка редактируются через «Изменить описание фотографии».

Неподходящую рамку можно убрать. На маленьких, размытых лицах и при сильном повороте возможны пропуски. Отметки сохраняются только после подтверждения. Распознавания личности и автоматического сравнения людей на разных снимках нет.

## Данные снимка

В редакторе доступны **место, год, событие**, уточнение даты или периода и история снимка. Все поля необязательны. Названия снимков не вводятся и не показываются; старое поле `title` сохранено для совместимости архивов. Год записывается четырьмя цифрами, например `1965`; приблизительную дату можно написать в поле периода. Пустые сведения скрыты. Снимки с заполненным местом автоматически появляются в разделе «Места».

В карточке человека есть отдельный портрет и кнопка **«Фотоальбом»**, которая показывает все снимки с подтверждёнными отметками этого человека. Нажатие на отметку фотографии открывает карточку.

## Альбомы и портрет

В галерее три режима: **«Все · по добавлению»**, **«По людям»**, **«По годам»**. Снимок с несколькими людьми входит в каждый их альбом. Неизвестный год и отсутствие отметок образуют отдельные группы. Для прежних снимков без `createdAt` используется обратный порядок записей, без выдуманной даты добавления. Неоднозначные периоды вроде «лето 1960» не превращаются в точный год автоматически.

В редакторе человека нажмите **«Из галереи»**, выберите снимок, передвиньте область и настройте масштаб. Можно также выбрать файл с компьютера. Обрезка создаёт отдельный квадратный PNG 640×640; в галерею он не добавляется. Исходный снимок остаётся прежним, его отметки не меняются. Обрезка сохраняется при сохранении карточки и входит в полный бэкап.

## Оригиналы и WebP

Оригиналы хранятся без перекодирования. **«Скачать оригинал»** возвращает именно загруженный файл. Для списков сервер по запросу создаёт WebP до 400 px по длинной стороне, для просмотра — до 1600 px. Маленькие снимки не увеличиваются; ориентация учитывается. Кодирование WebP — `lossless`, но уменьшенная копия не содержит разрешения оригинала. Для печати и архивного хранения используйте оригинал. Размер WebP не гарантированно меньше исходного JPEG.

Производные файлы кэшируются в `shared/previews`, отдельно от `uploads`, и не входят в полный бэкап. Ключ зависит от содержимого оригинала, размера и версии обработки. Задачи выполняются последовательно; одновременные запросы одной копии объединяются. При ошибке преобразования, анимации или превышении лимита 50 млн пикселей возвращается оригинал. Права доступа проверяются и для миниатюр. Внешние ссылки не скачиваются сервером.

Документация: [WebP в Sharp](https://sharp.pixelplumbing.com/api-output/#webp), [формат WebP](https://developers.google.com/speed/webp/docs/compression).

## Обработка

Используется SSD MobileNet из `@vladmandic/face-api`. Вычисления выполняются в браузере; фотографии не отправляются стороннему сервису. Модель загружается с этого сайта при первом поиске. Возраст, пол, эмоции и личность не определяются.

`npm run prepare:models` копирует модель детекции из закреплённой npm-зависимости в `public/models` перед `dev` и `build`. Каталог исключён из Git, сборка содержит модель. Результаты поиска рамок временно кэшируются в памяти вкладки. Ручная разметка доступна независимо от модели.

Поиск можно остановить, но уже запущенный расчёт может закончиться прежде, чем браузер обработает остановку.

Исходник: `src/vision/face-assistant.ts`. [Проект и лицензия FaceAPI](https://github.com/vladmandic/face-api).
