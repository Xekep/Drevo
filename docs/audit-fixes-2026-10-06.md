Проверки выполняются только на временных синтетических данных. Рабочая БД
не используется для нагрузочных, негативных или миграционных тестов.

Локально прошли typecheck, lint, production build, 3 built-worker теста и
полный прогон: 1275 pass, 0 fail, 2 skip. Первый вариант уменьшения работы ELK
вызвал регрессию геометрии и удалён; итоговые 31 тест геометрии прошли.
PostgreSQL CI прошёл, включая конкурентные записи и работу без superuser.
Окончательные браузерный и полный CI выполняются в PR #825.
Измерение времени одного fixture не доказывает ускорение на всех
древах; финальная геометрия идентична baseline.

Браузерные артефакты находятся в `benchmarks/audit-fixes-20261006/`:
11 страниц без найденных axe-нарушений, 7 ширин 320–1920 px без overflow,
console errors не обнаружены. Автоматический axe не заменяет ручную проверку
screen reader, реального touch и всего стандарта WCAG 2.2 AA.

Браузерный CI также выявил перекрытие текста карточки и Handle увеличенной
кнопкой ветви. Первоначальное перемещение под карточку ухудшило прежний дизайн.
7 октября по замечанию пользователя восстановлены компактная кнопка у портрета
и счётчик на всех видимых масштабах. Расширяется только прозрачная область
нажатия вправо, без увеличения самой кнопки. Проверены реальные попадания
курсора в дополнительную область, выбор карточки, сворачивание и создание связи.
Тест изменения средней раскладки начинает с открытой карточки:
дальний обзор сознательно скрывает кнопки отдельных ветвей. Проверки количества
людей и передачи предыдущей геометрии при сворачивании сохранены.
