# Загрузка архива

Первый ответ содержит облегчённый граф целиком: это позволяет сразу рассчитать всё дерево, не обрезая семьи по границе страницы. Биографии, источники, занятия и награды загружаются следом страницами по 40, затем — метаданные фотографий. Имена и связи на этих страницах повторно не передаются. Само изображение загружается при необходимости: небольшая WebP для списков и портретов, более крупная — при открытии фото, оригинал — для скачивания и обрезки.

В разделах «Люди», «Семьи» и «Фото» сначала создаются до 30 элементов. Следующие появляются при приближении к концу списка; кнопка «Показать ещё» остаётся запасным способом. Поиск и группировка работают по загруженным данным, поэтому счётчики во время загрузки могут дополняться.

Это поэтапная загрузка общего архива: метаданные в итоге присутствуют в памяти вкладки целиком. Здесь нет серверной пагинации поисковых каталогов, выгрузки невидимых карточек из памяти или получения ветви только при раскрытии. Такой подход сохраняет общий вид дерева и существующее сохранение с ревизией. Для существенно больших архивов следующий этап — отдельные запросы каталогов и объектов вместе с частичными операциями записи.

## Согласованность

`src/data/archive-pages.ts` объединяет только страницы одной ревизии и одного набора прав. Проверяются ожидаемое число записей, токен, дубли и идентификаторы. До завершения загруженный граф доступен для чтения; полного снимка для записи ещё нет. При ошибке, смене ревизии или закрытии доступа загрузка прекращается, интерфейс предлагает повторить её. Незавершённые данные никогда не отправляются полным `PUT`.

Ключ раскладки Worker содержит только геометрию и связи: приход биографии, наград или фото не меняет положение дерева. `useArchive` отвечает за загрузку и согласованный снимок; каталоги — за число видимых строк; сервер применяет права перед формированием каждой страницы. Публичные альбомы при закрытом древе не выдают людей, связи и персональные отметки.

## Проверка

Тесты проверяют сборку снимка из нескольких страниц, отклонение смешанных ревизий, дублей, чужих идентификаторов и отзыва доступа; HTTP-проверки — ограничения публичности и сохранение исходных фото. Ограничение DOM проверяется по реализации, а не измеренным FPS. В этой сессии браузер недоступен: интерактивное поведение, расход памяти и скорость на телефоне требуют проверки на устройстве.
