# Для агента

## Перед работой

1. Прочитать [правила репозитория](../../AGENTS.md).
2. Прочитать [локальную память](memory.md).
3. Открыть нужный документ из [инженерной документации](../engineering/README.md).
4. Сверить датированные сведения с кодом, тестами и состоянием релиза.

## Содержимое

- `memory.md` — решения, ограничения и контекст между сессиями.
- `audit-*`, `code-*`, `ui-*` и другие датированные отчёты — результаты
  конкретных проверок и исправлений.
- `layout-*` и [история отрисовки](render-performance.md) — эксперименты,
  измерения и ограничения проверенных вариантов.
- [`benchmarks/`](benchmarks/) — исходные результаты, схемы и артефакты замеров.

Рабочие контракты, инструкции установки и описание архитектуры находятся
в `docs/engineering/`. В памяти и отчётах не хранить секреты и личные данные;
остальные правила остаются в `AGENTS.md`.
