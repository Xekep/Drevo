# Композиция Drevo — 25 сентября 2026

Область проверки — весь проект: граф зависимостей `src`, точки сборки UI и сервера, владельцы ресурсов и состояния, HTTP/AI-контракты, раскладка, хранение, фоновые операции и эксплуатационные скрипты. Это целевой архитектурный проход, не повтор полного security-аудита или нагрузочного теста.

Основание: правила композиции из `TerraRuntime/src/AGENTS.md`: ответственность, владение состоянием и ресурсами, несколько конкретных зависимостей, отсутствие прозрачных обёрток. Название «PONY» в исходниках TerraRuntime не найдено; расшифровка не предполагается. Принципы закреплены в Drevo `AGENTS.md` для всех будущих изменений.

## Исправлено

| Область | Первопричина и последствия | Решение |
| --- | --- | --- |
| Сборка сервера | `sharing-http.ts` фактически собирал весь API, а не только публикацию ссылок. Восстановление и геокодирование искались через WeakMap-реестры: зависимость от порядка инициализации не была видна в аргументах. | `archive-http.ts` отражает настоящую роль. `index.ts` явно передаёт экземпляры и закрывает их; реестры и функции поиска удалены. |
| Резервирование | `backup-manager.ts` одновременно содержал SQL каталога, файловые проверки, tar/SSH и управление заданиями. Изменение хранения требовало работать в том же замыкании, что и аренда задания. | Три конкретных владельца: `backup-store`, `backup-files`, `backup-coordinator`. Старый manager удалён, CLI и HTTP используют координатор напрямую. |
| Окно исследователя | Состояние захвата указателя, ResizeObserver, ограничения размеров и история чатов находились в одной функции. Легко привязать движение окна к обновлению сообщений или нарушить очистку подписок. | `useResearchPanel` владеет геометрией и жестами. Сохранён существующий механизм изменения DOM во время движения, без рендера графика на каждом pointermove. |
| Анализ фотографий ИИ | Кэш выбора vision-модели и HTTP-вызов другого протокола были вложены в основной цикл исследования. | Конкретный адаптер `aiVision` владеет кэшем, заголовками, запросом, таймаутом и разбором ответа. Проверки доступности фото остаются в вызывающем исследовательском сценарии. |
| Контракт AI → браузер | `UiAction` был скопирован на сервер и клиент; тип ссылок повторял существующий доменный тип. Изменение одного определения не проверяло второе. | Общий `shared/research-protocol.ts`, ссылки переиспользуют `ResearchAnswerReference`. Серверные реализации не импортируются браузером. |
| Защита архитектуры | Правила границ были только текстовыми. | Автотест проверяет направления зависимостей и runtime-циклы, включая lazy imports. Работает в существующем CI вместе с остальными тестами. |

Изменения организации кода сохраняют маршруты, схему БД, алгоритм раскладки и порядок анимации. Единственное небольшое уточнение поведения: закрытый geocoder теперь сообщает «Поиск остановлен», а не ошибку длины названия.

## Решения по остальным областям

| Область | Решение и причина |
| --- | --- |
| `App.tsx` | Оставить точкой композиции разделов и панелей. Выбор принадлежит `useWorkspaceSelection`, камера — tree-компонентам. Большое количество JSX и передаваемых обработчиков само по себе не требует нового фасада. |
| `components/tree` | Сохранить существующих владельцев: `useFamilyView`, `useTreeLayout`, `useTreeCameraState`, Worker и чистые функции роста/рёбер. Не переносить камеру в оболочку и не дробить согласованный цикл появления карточек и линий ради длины `tree-canvas.tsx`. |
| `domain/kinship.ts`, раскладка союзов, маршрутизация | Это связные алгоритмы, а не сервисы с несколькими ресурсами. Сохраняем чистые функции и тестируем результаты; интерфейс на каждый этап вычисления не нужен. |
| `domain/research-tools.ts` | Большой диспетчер — явный перечень поддерживаемых возможностей. Не вводим динамическую регистрацию/плагины без потребности. Семейный граф и проверки аргументов остаются чистыми функциями. |
| `ai-research-runner.ts` | Координатор исследования остаётся большим: доступ, инструменты, предложения, провайдерный цикл. Выделена независимая внешняя граница vision; дальнейшее выделение обработчиков инструментов оправдано при изменении конкретного сценария, а не переносом замыкания в другой файл. |
| `research-assistant.tsx` | После выделения геометрии остаётся существенная сложность параллельных диалогов и SSE. Общие карты запросов, сообщений и отложенных UI-команд нельзя разнести по независимым хукам без единого владельца сессий. Это оставшийся долг, не объявляем его устранённым. |
| `hooks/useArchive.ts` | Ревизия, текущий снимок, сохранение и история отмены образуют один инвариант. Не разделяем их на несогласованные stores и не вводим глобальное состояние. |
| Редакторы человека, наград, админские формы | Состояние черновика и его валидация остаются рядом. Выделение каждого поля в компонент с собственным состоянием увеличило бы связанность. |
| Фото, документы, карта | Сохраняются отдельные HTTP-обработчики, файловое хранилище, превью и геокодирование. Кэш и жизненный цикл внешнего сервиса принадлежат адаптеру, права проверяются на HTTP/domain-границе. |
| `database.ts`, `schema.ts`, импорт/восстановление | Транзакции и миграции имеют явного владельца. Не создаём универсальный repository и вторую СУБД. Восстановление семейных данных по-прежнему проверяет ревизию и сохраняет текущие аккаунты. |
| `ops`, CI | Запуск плановых копий использует тот же координатор, что HTTP. Release-артефакт теперь включает `src/shared` рядом с `domain` и `server`, чтобы общие контракты не отсутствовали в развёрнутом исходном коде. Миграция СУБД, активация релиза и запуск фоновой задачи остаются разными эксплуатационными действиями. |

## Измеримые границы проверки

В начальной инвентаризации 254 TS/TSX-модулей: runtime-циклов и импортов серверной реализации из браузера не обнаружено. Новая автоматическая проверка дополнительно охватывает JS/MJS и запрещённые типовые зависимости. Она не доказывает отсутствие скрытой связи через DOM/CSS, сетевой формат JSON или вычисляемый путь dynamic import.

Проверки поведения: managed backup/restore, права и устаревшая ревизия; HTTP маршрутизация и геокодирование; AI HTTP и работа с фотографиями; E2E параллельных чатов, Markdown/графиков, перемещения/размера окна, мобильных взаимодействий, роста и переходов дерева. Используются изолированные тестовые базы и имитация AI, без изменения production-данных и платных запросов модели.

## Дальнейшие границы

При следующем расширении параллельных чатов выделять единый владелец состояния сессий, сохраняя отмену только выбранного запроса и привязку результата к исходному чату. Для протокола HTTP/SSE общие TypeScript-типы не заменяют runtime-валидацию входа.

Большой исследовательский цикл и зависимость позиционирования кнопки ИИ от DOM дерева остаются кандидатами для последующего изменения при работе над этими сценариями. Это не блокеры, требующие немедленной переписи UI. PostgreSQL остаётся отдельным отложенным пунктом дорожной карты.
