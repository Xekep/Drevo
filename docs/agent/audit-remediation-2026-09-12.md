## Проверка

- `npm run typecheck` — успешно.
- `npm run lint` — успешно.
- `npm test` — 275/275.
- `npm run test:worker` — 1/1 на production bundle.
- `npm run build` — успешно; основной entry 193,95 КБ (61,71 КБ gzip), Human загружается отдельно 1 558,38 КБ (409,37 КБ gzip).
- `npm run test:e2e` — 5 проверок прошли, mobile-дубликат проверки модели штатно пропущен: desktop, 390×844 mobile, навигация, overflow и фактическая загрузка трёх моделей Human без console errors.
- `npm audit --audit-level=low` — 0 vulnerabilities.
- `git diff --check` — без whitespace errors.
- Диагностический backup 10 000 людей после шести изменений: 63 574 016 байт; restore preview — HTTP 200, 324 мс. Это функциональный сценарий, не нагрузочный benchmark.

## Что нельзя считать проверенным до выкладки

- Не применялись `ops/nginx.conf`, `drevo-backup.service` и `drevo-backup.timer` на production-сервере.
- Не выполнен реальный off-host restore drill, поэтому заявленный timer даёт проектный RPO до 24 часов, а фактический RTO пока не измерен.
- Не проводился destructive failover и benchmark на 1 000/10 000 одновременных клиентов.
- Human прошёл typecheck, production build, загрузку всех трёх моделей в Chrome без console errors и API-тесты формата embeddings. Качество распознавания на представительном наборе семейных фотографий требует отдельной приёмки; это измерение качества модели, а не незакрытая уязвимость старой зависимости.
