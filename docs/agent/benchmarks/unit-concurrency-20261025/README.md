# Очередь unit-тестов: 25 октября 2026

Одинаковые 352 файла, Node 22.23.2, одна Windows-машина; прогоны выполнялись
последовательно, без одновременного второго измерения. Измеряется время очереди
от запуска файлов до завершения всех процессов, без загрузки npm.

| Режим | Время | Результат |
| --- | ---: | --- |
| Один процесс | 474,597 с | 1619 passed, 2 skipped, 0 failed |
| Два процесса | 257,289 с | 1619 passed, 2 skipped, 0 failed |
| Два процесса, порядок перемешан (`seed=20261025`) | 246,202 с | 1619 passed, 2 skipped, 0 failed |

Ускорение в этом сравнении — **1,84×**, время сократилось на **45,8%**.
Это один последовательный замер и два параллельных, а не гарантия такого же выигрыша
на любой машине. Повторный прогон с другим порядком сохранил результаты каждого
файла, без новых пропусков или ошибок. Версия Node, CPU, времена каждого файла и отпечаток одинаковых
счётчиков тестов сохранены в [results.json](results.json).

`ops/run-unit-tests.ts` сохраняет прямой запуск отдельного Node-процесса для
каждого файла, который использовался в CI для обхода ошибки IPC `node --test`.
Параллельность ограничена двумя файлами, внутри файла порядок не меняется.
Ни один файл не исключён; отсутствие TAP-сводки, ненулевой выход, ошибка теста
или таймаут делают результат неуспешным. Полные логи файлов не смешиваются
и сохраняются рядом с JSON-отчётом. Пять тестов самого запускателя проверяют
границу параллельности, отдельные процессы, сбой одного файла, отсутствие тестов,
длинный лог, зависание и отмену очереди.

Повторение:

```sh
npm run test:serial -- --report=outputs/bench-serial/report.json
npm test -- --concurrency=2 --report=outputs/bench-parallel/report.json
npm test -- --concurrency=2 --seed=20261025 --report=outputs/bench-shuffled/report.json
```

Это измерение файлов unit/HTTP-проверок. Собранный Worker, браузерные сценарии
и PostgreSQL остаются отдельными этапами; время всего деплоя не обязано
уменьшиться в той же пропорции.
