# Точные запросы ИИ к событиям и местам

`query_events`, `query_places`, `get_event` и расширенный `query_people`
вычисляют результаты чистым доменным кодом. Модель выбирает условия и объясняет
полученные записи. Инструменты получают уже разрешённую пользователю проекцию
архива; произвольных SQL, HTTP и прямой записи в БД здесь нет.

## События

Пример: все записанные браки в Екатеринбурге между 1900 и 1920 годами:

```json
{
  "criteria": {
    "type": "marriage",
    "placeContains": "Екатеринбург",
    "yearFrom": 1900,
    "yearTo": 1920
  },
  "offset": 0,
  "limit": 50
}
```

`query_events` рассматривает рождения, смерти, события карточек и этапы общих
союзов. Этап союза считается один раз, даже если относится к двум людям.
Поддерживаются `personId`, `titleContains`, `hasSources`, `sourceType`,
`sourceTitleContains`, `sourceReferenceContains`. Условия соединяются через И:
в одном событии и, для source-полей, в одном прикреплённом источнике.
Границы лет включительные, относятся к году начала. Неизвестная дата и свободный
текст приблизительной даты не превращаются в год. Неполные корректные даты
с известным годом участвуют в отборе. Тип источника сравнивается точно после
нормализации регистра/ё; текстовые Contains-поля ищут подстроку.

`get_event` принимает только `eventId`, полученный из результата запроса,
и повторно ищет запись в разрешённой проекции. Внутренний ID не предназначен
для вывода пользователю и не предоставляет доступ к записи.

## Связанные условия людей и мест

В `query_people.criteria` доступны `eventType`, `eventPlaceContains`,
`eventYearFrom/To`, `eventSourceType`, `eventSourceTitleContains`,
`eventSourceReferenceContains`. Они относятся к одному событию и одному его
источнику, в том числе если заданы в разных группах `allOf`.
Источник общего раздела карточки не становится основанием события.

```json
{
  "criteria": {
    "eventType": "marriage",
    "eventPlaceContains": "Екатеринбург",
    "eventSourceType": "Архив"
  }
}
```

`query_places.criteria` поддерживает `nameContains`, `nameEquals`,
`hasCoordinates` и `event` с теми же условиями, что у `query_events`.
Сначала отбираются события, затем группируются записанные названия мест.
При отсутствии `event` также учитываются разрешённые фотографии.
Исторические названия не объединяются автоматически. Одинаковое текстовое
название может соответствовать нескольким населённым пунктам: координаты
возвращаются отдельными вариантами, без предположений о переездах.

## Страницы и основания

`total` считается по всей выборке; `limit: 0` возвращает только подсчёт.
Размер страницы — по умолчанию 50, максимум 100. Компактные результаты
ограничены также бюджетом около 24 тысяч символов записей на страницу:
при сокращении выставляется `responseLimited`, продолжение — по `nextOffset`.
Нельзя считать количество по длине одной страницы.

`evidence` содержит человека, ссылку на конкретное событие и до трёх кратких
прикреплённых источников. Отбор источников учитывает исходные условия.
`sourceCount` и `matchingSourceCount` отличают все привязки от совпавших.
В местах возвращаются ограниченные примеры, полные количества остаются точными.
Полные сведения читаются в карточке или через `get_sources.summary`, включая
источники общих союзов. Область `scope` различает дату, место, событие и союз: источник
союза сам по себе не доказывает отдельно дату или место. Старые claim-цитаты
используются только при совпадении значения с текущим полем.

Модель получает правило ставить готовые Markdown-ссылки прямо возле вывода,
различать записанный факт и доказательство, не показывать служебные ID.
В браузере ссылка открывает нужный профиль, вкладку и запись с фокусом и
подсветкой в новой вкладке; текущий чат сохраняется. Ссылка не заменяет
проверку доступа. Локатор источника совпадает с его объединённой карточкой
в разделе «Источники», включая источники общих союзов.

Проверки: `tests/research-record-query.test.ts`, существующие тесты фильтров,
инструментов и источников; браузерный сценарий
`tests/e2e/research-evidence-links.spec.ts` проверяет Markdown-ссылку из чата,
открытие события, фокус и переход на вкладку источников.
