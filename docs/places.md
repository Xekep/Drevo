# Места семьи

Круглые метки показывают портреты людей из карточек. При нескольких людях в одной точке видны до трёх портретов и общее число уникальных людей; рождение и смерть одного человека не удваивают счётчик. Сначала показываются доступные фото, затем силуэты. Если фото отсутствует или не загрузилось, остаётся нейтральный силуэт. Нажатие открывает связанные события и переход к человеку.

Раздел **«Места»** строится автоматически из `birthPlace` и `deathPlace` карточек. Каждое событие связано с человеком; точка открывает список рождений и смертей с известными датами, а имя ведёт к карточке на древе. Пустые места не создаются. На телефоне карта и список доступны для просмотра.

Линии миграции не рисуются: места рождения и смерти ещё не описывают весь путь человека. Для следующего этапа нужны отдельные подтверждённые события проживания с периодами и источниками. Карта использует современные очертания и населённые пункты, а не границы государств прошлого.

## Исторические названия

В карточке вводите название из семейного документа. Исходный текст никогда автоматически не заменяется современным. После выхода из поля приложение ищет координаты; найденная однозначная точка сохраняется вместе с карточкой. Уже заполненные карточки ищутся при открытии карты без повторного редактирования.

Обычный поиск работает через [Photon](https://github.com/komoot/photon). Если нет однозначного точного результата, сервер ищет название и альтернативные имена в [Wikidata](https://www.wikidata.org/wiki/Wikidata:Data_access), затем читает географические координаты найденного объекта. **В коде нет списка подстановок «старый город → новый город».** Совпадение должно быть точным, объект — иметь географические сведения и единственную подходящую земную координату. Неоднозначность остаётся вопросом для уточнения, а не превращается в случайную точку.

Справочники неполны: деревня, исчезнувшее поселение, местное название или запись с ошибкой могут не найтись. Название и человек при этом остаются в списке. Редактор может уточнить поисковый запрос, выбрать найденный вариант либо указать точку на карте. Историческая запись остаётся прежней. Ручное уточнение действует только на доступные для редактирования карточки с этим названием и сохраняется через обычную проверку прав и версии.

## Хранение и внешние сервисы

- Уточнённые `birthLocation` и `deathLocation` содержат `{place, lat, lon, label?}` внутри JSON человека. `place` привязывает координаты к исходной записи: смена названия не переносит старую точку на новое место. Поля входят в JSON и резервные копии; отдельная миграция таблицы людей не нужна.
- Автоматические ответы кэшируются в таблице `geocode_cache` SQLite на 180 дней, максимум 5000 записей. Это служебный кэш, не генеалогические факты; он не увеличивает `revision` и не входит в JSON-экспорт.
- Сервер передаёт справочникам только строку места, без ФИО, дат и связей. Запросы выполняются последовательно, не чаще одного за 1,2 секунды для всего процесса, с ограничением 1000 внешних запросов в сутки и паузой после ограничения со стороны провайдера. На карте автоматически обрабатываются первые 50 мест; следующие запускаются кнопкой. Результаты переиспользуются между посетителями.
- Photon допускает умеренное использование общего сервера без гарантий доступности. Провайдер можно заменить переменной `GEOCODER_URL` (совместимый Photon API); исторический API — `HISTORICAL_GEOCODER_URL` (совместимый Wikibase Action API). Для большого архива потребуется собственный или договорной сервис.
- Подложка — [Leaflet](https://leafletjs.com/) и [OpenStreetMap](https://operations.osmfoundation.org/policies/tiles/). Загружаются только видимые тайлы, браузер использует обычный HTTP-кэш, атрибуция остаётся видимой. Офлайн-скачивание тайлов не предусмотрено. При недоступности подложки список мест и людей остаётся доступным.

Компонент карты загружается отдельным JavaScript-модулем при открытии раздела. Географическая группировка и разбор результатов — `src/domain/places.ts`, HTTP и кэш — `src/server/geocoding.ts`, интерфейс — `src/components/places-map.tsx`. Префикс Leaflet в подписи карты отключён; указание OpenStreetMap остаётся.
