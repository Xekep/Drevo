# Временные ссылки на семью

Администратор на компьютере выбирает человека, включает «Семья выбранного», раскрывает нужные ветви и нажимает «Поделиться». В компактном диалоге показаны количество людей и срок: 1 час, 1, 7 или 30 дней. Список людей раскрывается нажатием на количество, название для каталога формируется по выбранному человеку. «Создать и скопировать» создаёт ссылку и сразу записывает адрес в буфер. Подтверждение и срок появляются в том же окне; повторное нажатие копирует уже созданную ссылку. Если буфер недоступен, в этом окне появляется поле для ручного копирования. Ссылка даёт просмотр без Яндекс ID, даже если весь архив закрыт.

Состав определяется людьми в семейном режиме, а не прямоугольником камеры. Человек за краем экрана тоже включается; полный список виден перед созданием. Набор идентификаторов фиксируется. Новые родственники не добавляются автоматически; исправления включённых карточек отображаются, удалённые люди исчезают.

Доступны карточки, события, источники, награды, локальные портреты и связи между включёнными людьми. Альбомы, фотографии галереи, общие метаданные, пользователи и аудит недоступны. Внешние портреты не подгружаются. Текст биографий и источников не редактируется автоматически: проверяйте публикуемые сведения перед выдачей.

Адрес `/s/<случайный-токен>` копируется в буфер при создании. В базе хранится только SHA-256 токена: повторно получить адрес из каталога нельзя, сохраните его при выдаче. Каталог в админке показывает название, количество людей, автора, даты и статус. Активную ссылку можно отозвать, история выдач остаётся.

Сервер проверяет срок и отзыв при каждом запросе данных и портрета. Ответы не кэшируются; страница просит не индексировать её и не передавать адрес в Referer. Открытый экран проверяет доступ каждые 30 секунд, при возвращении во вкладку и закрывает данные по сроку. Уже сохранённые гостем сведения невозможно удалить с его устройства.

## API

- `POST /api/shares`, JSON `{anchorId,personIds,title,durationHours}`, `If-Match` с ревизией. Только администратор; конфликт — 409.
- `GET /api/shares?before=<курсор>` — каталог администратора, 100 записей на страницу.
- `DELETE /api/shares/<id>` — отзыв.
- `GET /api/shared/<token>` — разрешённый фрагмент независимо от обычной сессии.
- `GET /api/shared/<token>/portrait/<personId>` — только портрет включённого человека. После отзыва или истечения — 410.

Токен не является сессией и не принимается обычными API. Таблица `share_links` не имеет внешних ключей на `people`: сохранение архива пересобирает людей. Каталог включается в SQLite-бэкап. Восстановление семейных данных через админку не подменяет действующие ссылки записями из загруженной базы.
