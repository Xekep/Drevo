# Исправления аудита кода — 28 октября 2026

Исходный срез: `main` на `9eea580c`. Исправления относятся к шести группам
замечаний; смена стека и удаление истории миграций не требуются.

## ИИ и уточнения

Убраны перехваты родства и справочника по русским фразам, подмена составного
ответа готовым ответом одного инструмента и словарь замены темы при уточнении.
Модель получает исходные реплики и выбирает структурированный инструмент.
Код проверяет доступные ID и вычисляет родство. Уточнение инвалидирует
неподтверждённые действия ответа, но не применяет и не отклоняет предложения
изменения БД. Проверки включают имя «Владимир», отрицание, составную задачу и
уточнение после создания ожидающего подтверждения предложения.

## Изменения архива

Действующий HTTP delta-путь использует `patchPeople` или `patchChanges`.
Второй загружает компактную проекцию графа для проверки циклов, дат и доступа,
полный JSON — только для целей изменений. Сохраняются общие проверки авторства,
цитат, медиа, квот, ревизии и аудита. История хранит обратимые изменения;
восстановление старого снимка остаётся отдельной полной операцией.
Перенумерация строк выполняется пакетно, запись принимает именованные options.

[Измерение на 1001 вымышленной персоне](benchmarks/archive-mutations-20261028.json):
объём JSON результатов выборок 283 641 байт против полного снимка 16 837 616
байт; два локальных запроса 226 и 317 мс. Это отдельные измерения PostgreSQL
16.2, не нагрузочный тест и не измеренное ускорение относительно прежнего кода.
Чужие данные и рабочая БД не использовались.

## Фрагменты

Первоначальное чтение поддерживает ограниченное серверное окно, последующие
раскрытия запрашивают новые окна с токеном ревизии и области доступа.
Настройки пользователя и продолжения ветвей сохраняются. Полный обзор явно
догружается для операций, которым нужен полный граф; такая загрузка не сбрасывает
уже выбранное окно. Топология на сервере остаётся O(V+E) и использует общий
ограниченный кеш. Технический предел 10 000 не повышен.

Названия родства окна рассчитываются сервером по всему разрешённому графу.
Частичный граф браузера не выдаётся за полные генеалогические данные. Скрытые
люди не участвуют в счётчиках и пороге активации. Детали протокола и ограничения
описаны в [архитектуре](architecture.md) и [полотне](tree-workspace.md).

## Проекции и режимы

SQL и domain используют один список исключаемых подробностей overview.
События карты, хронологии и имена галереи имеют собственные типы и больше не
выдаются за полный `Person`. Цитаты в исходных карточках сохраняются.

`tree-view-policy.ts` задаёт приоритет представлений и допуски фрагмента,
жестов и слоёв. `use-tree-view-state.ts` владеет атомарными переходами и токеном
асинхронной подготовки. Подготовленный переход исполняется по актуальному
зафиксированному графу; запоздалое наведение не открывает закрытый веер.

## Удалённые остатки

Удалены недоступная цепочка PNG-экспорта, прежний генератор вертикальной шкалы,
неиспользуемый генератор архивных отчётов, обёртка прежнего анализатора родства
и функции без вызовов. Проверки источников действующих экспортов сохранены.
С внутренних констант и функций сняты ненужные экспорты; публичные типы
контрактов, рабочие CLI и миграции не удалялись по одному отчёту анализатора.
