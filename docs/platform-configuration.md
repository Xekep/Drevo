# Общие настройки платформы

В PostgreSQL лимиты загрузок, подключение VK ID и справочник ресурсов поиска едины для всех древ. Их меняет только администратор платформы с действующим сеансом. Владелец древа без этого права не получает доступ к настройкам, даже если он управляет участниками и данными своего древа. Публичный просмотр справочника ресурсов доступен читателю древа; право на изменение справочника из этого не следует.

При первом запуске после обновления основной архив, указанный через `ARCHIVE_ID`, переносит свои действующие лимиты, настройки VK ID, категории и ресурсы в общие таблицы. Сохраняются идентификаторы, порядок, настройки поиска ИИ и собственные ресурсы основного архива. Если его справочник пуст, используется стартовый список. Повторный запуск не перезаписывает уже общие настройки. Сервер выбранного архива не выполняет первичный перенос.

Старые записи других архивов остаются в их таблицах для отдельной операторской инвентаризации и ручного переноса, но не становятся частью общего справочника автоматически. Приложение не публикует объединённый список приватных ссылок. Перед ручным переносом оператор должен проверить право на публикацию каждой записи и её URL, включая параметры запроса. Самостоятельного интерфейса инвентаризации и переноса в этом этапе нет.

Общие настройки входят в системную резервную копию PostgreSQL. Переносимый архив отдельного древа и его прежние локальные строки больше не являются резервной копией действующих общих настроек. При восстановлении всей платформы нужно восстанавливать системную БД, а не полагаться на архивный TAR отдельного древа.

Общий лимит загрузок применяется по текущей глобальной роли и роли читателя в древе; локальная роль читателя не повышается глобальным назначением. Отдельная квота базового аккаунта владельца (500 МБ и 150 человек) продолжает действовать независимо от общего лимита. Локальный SQLite-режим сохраняет прежние настройки одного древа.

MCP-токены и резервные копии открываются отдельными разделами `/admin`. Это операции конкретного архива: администратор выбирает древо из своих одобренных архивов, а форма перепроверяет сеанс и владение перед загрузкой. Для MCP дополнительно нужен доступ к ИИ-функциям. Выбор другого архива очищает прежние токены, выданный секрет и предпросмотр восстановления; все HTTP-адреса явно относятся к выбранному древу. Глобальное право администратора без владения архивом не позволяет выпускать его полные MCP-токены или восстанавливать его копии. Разделы не загружают семейный граф.
