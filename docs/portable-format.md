# Переносимый пакет Drevo

`GET /api/drevo/export` отдаёт ZIP с расширением `.drevo` владельцу выбранного архива. В личном кабинете файл можно скачать и загрузить в другое **пустое** дерево Drevo. Импорт не объединяет два существующих дерева и не перезаписывает людей.

Версия 1 содержит:

- `manifest.json`: `format: "drevo"`, `version: 1`, время экспорта и для каждого вложения путь, размер и SHA-256;
- `archive.json`: карточки людей, семейные и дополнительные связи, фотографии, источники, документы с привязками и аннотациями, обсуждения карточек;
- `media/`: оригиналы локальных фотографий, портретов и PDF. Внешние URL сохраняются как ссылки в JSON, без скачивания внешнего содержимого.

`archive.json` ограничен 128 МиБ, чтобы запрос экспорта не занимал неограниченную память. Оригиналы передаются потоком; их SHA-256 вычисляются перед началом ответа, поэтому большой архив может некоторое время готовиться без видимого прогресса.

Контрольные суммы обнаруживают повреждение файла, но не удостоверяют автора пакета. `POST /api/drevo/preview` проверяет версию, список файлов, SHA-256, связи данных и безопасные пути, затем показывает количество людей, фото, документов и обсуждений. `POST /api/drevo/import` по одноразовому токену повторно проверяет файл перед записью. Оригиналы получают новые имена, чтобы разные деревья не делили один физический файл. Изменение БД выполняется транзакционно с проверкой ревизии, прав владельца и квот; скопированные файлы удаляются при ошибке. Предпросмотр действует 30 минут. Для большого пакета нужны свободное место под файл и его распаковку и время на две проверки хешей.

Импорт переносит сведения людей, связи, фото, источники, PDF, аннотации и обсуждения. Имена авторов обсуждений сохраняются, но старые ID авторов не дают им права на редактирование в новом дереве. Владелец нового дерева становится загрузившим документы. Внешние URL остаются ссылками.

Пакет не является системной резервной копией: он не включает пароли и токены, роли и приглашения, настройки сервера, AI-диалоги и журналы эксплуатации. История правок также пока не переносится. Для восстановления всего сервера используются системные резервные копии, доступные только администратору платформы.
