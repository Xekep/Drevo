# Совместимость после миграций

Проверено по коду 18 октября 2026 года. Работающий сайт использует PostgreSQL;
наличие SQLite в репозитории не означает, что сайт продолжает писать в неё.

## Что убрано

- В PostgreSQL-режиме `generated-research-files.ts` после записи хранит только
  метаданные временного файла, без `Buffer`. Скачивание читает общий диск после
  проверки прав и метаданных сообщения. Общий физический лимит 64 МиБ, резерв
  диска, блокировка установки и удаление файлов сохранены. Локальный SQLite
  по-прежнему использует ограниченный кеш байтов.
- Клиенты кабинета и переключателя древ используют обязательный `href` сервера.
  Email-вход использует выданный сервером `path`; отсутствие или внешний адрес
  приводит к ошибке формы, без построения старого `/a/<id>/tree`. Вход аккаунта
  без древа по-прежнему ведёт в `/account` и не требует `path`.
- Расширения схемы PostgreSQL собраны в `postgres-runtime-migrations.ts`:
  проверка установки, SQL-файл, вид транзакции и особые случаи конкурентной
  установки описаны вместе. Исполнитель сохраняет порядок и блокировки.
  Проверка установки повторяется внутри блокировки, в том числе для индекса
  ссылок на источники документов. Заполнение данных отдельного архива остаётся
  в `postgres-runtime-schema.ts`, под RLS.

Реестр не заменяет историю SQL и не является новым журналом версий базы.
Каталожные проверки остаются нужны для прежних и частично обновлённых установок;
в пределах общего пула они выполняются один раз, а не на каждом запросе.

## Что пока необходимо сохранить

| Код | Почему нужен | Условие следующего изменения |
| --- | --- | --- |
| Нумерованные `ops/postgres/*.sql` | Чистая установка, обновление и тестирование промежуточных схем | Не удалять в рамках уборки. Новый базовый снимок требует отдельной проверки путей обновления |
| SQLite и второй диалект `StoreDatabase` | Локальный запуск, тесты, импорт исходной базы и переносимые старые копии | Отдельное решение о прекращении поддержки этих сценариев; сейчас удаление сломает их |
| Старые `/join/<archive>/<token>` | Уже отправленные приглашения должны работать до истечения срока | R7.1: доказать истечение или отзыв всех старых ссылок; максимум 720 часов от последней выдачи старым релизом |
| Наследование пустого профиля роли ИИ | Старые сохранённые настройки могут ещё опираться на общую модель и лимиты | R7.2: сначала перенести эффективные значения четырёх ролей, проверить права, бюджеты и повторный запуск |
| `demo-cleanup.ts` | Однократное обновление старых архивов; при наличии маркера не читает весь архив | До переноса в отдельный путь обновления учесть восстановление прежних копий. Удалять без такой проверки нельзя |
| Редиректы старых адресов | Сохранённые пользователями закладки | Не путать с удалённым клиентским построением URL; редирект не заменяет авторизацию |

Существующие резервные копии и их формат этим изменением не затрагиваются.
Служебные импортёры и проверки миграций могут запускаться CLI/CI без импорта
из приложения: это само по себе не делает их неиспользуемым кодом.
