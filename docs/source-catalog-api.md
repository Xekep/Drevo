# Каталог источников

Каталог хранит один источник с архивными реквизитами и ссылками на уже загруженные документы. Доступ к `/api/sources` пока имеет администратор архива. Все изменяющие запросы требуют обычной сессии и того же Origin, что и архив.

`GET /api/sources` возвращает `{ "sources": [...] }`, а `GET /api/sources/:id` — `{ "source": ... }`. У записи есть `id`, `version`, `title`, `type`, `author`, `institution`, `archive`, `fond`, `opis`, `delo`, `sheet`, `reference`, `url`, `accessedAt` (формат `ГГГГ-ММ-ДД`), `description` и `documentIds`. Массив `documentIds` содержит ID файлов из каталога документов этого же архива. При создании через `POST /api/sources` достаточно передать название; остальные текстовые поля и список документов могут быть опущены. Сервер назначает ID и начальную версию 1.

`PUT /api/sources/:id` принимает изменяемые поля и текущую `version`; устаревшая версия даёт 409. `DELETE /api/sources/:id` принимает `{ "version": 2 }` и отклоняется, пока источник подтверждает хотя бы один факт.

`POST /api/sources/:id/links` принимает `{ "personId": "...", "eventId": "...", "revision": 7 }`. `eventId` можно опустить, чтобы подтвердить карточку человека. `DELETE` по тому же адресу и с тем же телом снимает связь. Один источник можно связать с несколькими карточками и событиями. Устаревшая ревизия архива даёт 409. Вложенные источники старых архивов остаются доступными без конвертации; при необходимости их можно вручную перенести в каталог.

При привязке можно указать `documentId` из записи источника и `documentPage` от 1 до 2000. Если документ не указан, берётся первый прикреплённый документ.

Полный пакет Drevo включает каталог и его ссылки. GEDCOM сохраняет текст цитаты для совместимости с другими программами; реквизиты каталога как отдельную сущность этот формат не переносит.
