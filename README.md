Семейный архив с генеалогическим графом, исторической шкалой, русскими названиями родства и фотографиями с отметками людей.

**React + React Flow + TypeScript · Node.js · SQLite · Vite.** Интерфейс собирается в статические файлы, данные загружаются и сохраняются через AJAX. База и фотографии находятся на вашем компьютере или на вашем сервере.

## Запуск на компьютере

Нужен Node.js **22.13 или новее**; на сервере и в CI используется 22.23.2.

```powershell
cd C:\Users\Xekep\Documents\GitHub\Drevo
npm ci
npm run dev
```

Откройте **http://127.0.0.1:3000**. Локальный сервер слушает только этот компьютер, вход не требуется. При первом запуске создаётся пустой архив `data/drevo.sqlite`. Нажмите «Добавить первого человека». Последующие запуски сохраняют ваши данные.

Локальный и серверный архивы независимы. Для переноса данных используйте бэкап или экспорт/импорт JSON и отдельно переносите `uploads/` с фотографиями.

Для анализа нейронками: **[JSON без фото](https://drevo.kiiko.ru/api/export.json)** (`GET /api/export.json`). Люди, даты, места, источники и связи с пояснениями; без фотографий, отметок и служебных полей. Доступен всем при публичном древе, иначе — после входа с любой ролью. В меню проекта есть скачивание **«Экспорт JSON без фото»**. Это формат анализа, для восстановления используйте бэкап. [Описание полей и доступа](docs/api.md#json-для-анализа).

Для запуска собранной версии:

```sh
npm run build
npm start
```

## Как вести семейный архив

1. Нажмите **«Добавить → Человека»**. Введите ФИО одной строкой: фамилия, имя, отчество. **Достаточно фамилии и имени**; портрет можно добавить сразу или позже. Дата рождения и пол необязательны и находятся в «Дополнительных сведениях» вместе с биографией, местами и источниками. Дата может быть точной (`1950-05-12`) или только годом (`1950`). Части составного ФИО можно уточнить отдельно.
2. В карточке нажмите **«Родственник»**, выберите роль и **«Новый человек»** либо **«Уже в древе»**. Соединение можно также протянуть между точками карточек или выбрать двух людей кнопкой **«Связь»**. Сначала показывается предложение, затем связь сохраняется. Родительское направление идёт **от родителя к ребёнку**.
3. Нажмите **«Изменить»** в карточке — форма откроется справа, сохраняя дерево перед глазами. Нажатие на линию открывает её участников, тип и доступное примечание. Конец линии можно перенести к другому человеку; изменение сохраняется одной операцией. Признак «Все кровные родители известны» помогает отличать неполнородное родство от неполных данных.
4. Выберите **«Родство»** и два имени. Панель покажет роли и цепочку связи. Если протянуть соединение в пустое место, появится **«+ Добавить родственника»**: новый человек и связь сохраняются вместе.
5. Нажмите **«Добавить → Фотографию»** или откройте галерею из меню. Перетащите снимок в окно, проверьте предпросмотр и заполните известные сведения. **«Сохранить и отметить людей»** открывает фото с автоматическим поиском рамок. Выберите рамку и человека; пропущенную рамку можно нарисовать вручную. Если человека ещё нет, создайте его прямо из просмотра фото, затем продолжите разметку.
6. Портрет карточки загружается прямо в форме человека; при желании его можно выбрать из галереи или по ссылке. Все снимки, на которых человек отмечен, появляются в его карточке.
7. Кнопка **«Фотоальбом»** в карточке открывает все снимки с отметками этого человека. **«Семьи»** показывает группы известных родителей и детей с переходом к группе на древе.

Над деревом — только число людей и поколений. Полная сводка с диапазоном лет и продолжительностью истории находится в **«О проекте»**. Описание проекта и его возможностей сохранено; убран только спойлер **«Как пользоваться деревом»**. Глубина поколений считается по записанным родителям, годы — по датам рождения и смерти. В **«Дополнительных сведениях → Награды»** добавляются название, год и источник; в карточке каждая награда показана значком с раскрываемым источником. Награды включены в бэкапы и JSON для анализа. [Правила расчёта и хранения](docs/data-model.md).

При открытии карточки умершего небольшой белый **рисованный голубь** сразу улетает от верхней строки ФИО вверх через область портрета. Один пролёт длится 1,9 секунды и работает также на телефоне; наведение не требуется. Птица не добавляет отступов и не перехватывает нажатия. При `prefers-reduced-motion` остаётся неподвижный символ. Символ появляется только при записанной дате или месте смерти; возраст сам по себе не считается подтверждением смерти. [Изображение и параметры анимации](docs/memorial-dove.md).

Братья и сёстры определяются автоматически через родителей. Совпадающие фамилия и отчество дают подсказку о возможном родстве в форме и карточке человека; для подтверждения предлагается уточнить общего родителя. Прямого пункта «Брат / сестра» в списке связей нет. При создании связи родитель/ребёнок первоначальный порядок предлагается по датам рождения; его можно изменить перед сохранением. [Правила и примеры](docs/name-hints.md), [покрытие терминов родства](docs/kinship-coverage.md).

После загрузки снимка автоматически запускается поиск лиц. Модель предлагает рамки; вы выбираете человека и подтверждаете отметку. Обработка выполняется в браузере, модель загружается с этого сайта. Для фото можно указать место, год, событие и описание; незаполненные сведения не показываются. Подробнее: [помощник разметки фото](docs/photo-assistant.md).

Основное полотно без точечной сетки имеет два представления: **«Древо»** с компактными семейными ветвями и **«Хронология»** с реальными годами и эпохами. В «Древе» люди одного поколения могут находиться на разных высотах: важнее сохранить рядом семью, чем выстроить весь архив в одну линию. Выбранный человек сохраняется при переключении. В верхней строке слева — логотип и разделы, справа — поиск, добавление и меню аккаунта. На телефоне разделы открываются через меню. Там же — **«О проекте»** с историей проекта и сводкой архива. Панель выбранного объекта открывается справа, на телефоне — снизу.

В «Древе» каждый союз получает собственный блок: повторные браки не объединяют всех супругов в одну семью. Дети без собственной ветви собираются небольшими рядами под своими родителями. Для слишком широкого дерева приложение сравнивает несколько раскладок семейных блоков и выбирает более компактную. Дети отходят общей веткой от родителей; при нажатии мышью можно выбрать конкретную родительскую связь. При необходимости человек отображается в нескольких блоках со значком перехода между ними — запись в архиве остаётся одна. Расположение и маршруты рассчитывает ELK в Worker. Пересечения разных ветвей обозначаются разрывом линии, дополнительные отношения переключаются кнопкой «Доп. связи». В хронологии годы остаются точными. Для сложного графа абсолютное отсутствие пересечений не гарантируется. [Правила компактной раскладки](docs/family-layout.md).

В хронологии супруги перемещаются по горизонтали вместе. Между ними проходит единая линия, на которой выбирается общая точка подключения детей. Конфликтующие ветви пересчитываются с учётом остальных семей; проверяются короткие вертикальные и боковые входы. Точные годы и отдельные типы родства сохраняются. [Оптимизация хронологии и результаты проверки](docs/timeline-layout.md).

**Телефон — для просмотра, компьютер — для редактирования.** На телефоне доступны дерево, эпохи, карточки, родство, места и альбомы. По умолчанию показано всё древо. После выбора человека появляется «Семья выбранного»; «Всё древо» возвращает полный обзор, а кнопка вписывания меняет масштаб видимой части. Добавление людей и фото, редактирование связей и админка доступны при ширине окна от 900 пикселей и наличии мыши или тачпада.

При нажатии на человека мобильная карточка раскрывается на весь экран поверх меню. Её можно свернуть верхней кнопкой или закрыть свайпом вниз за заголовок. Полотно сохраняет размер под панелью. Двойное касание свободного места приближает древо; удержание второго касания и движение вверх или вниз позволяет менять масштаб одним пальцем. На сенсорном экране линии пропускают касания для перемещения и масштаба; сведения о родстве доступны через карточки людей и сравнение. В разделе «Места» карту видно на весь доступный экран, список открывается кнопкой и тоже закрывается свайпом за заголовок.

[Аудит кода, архитектуры и интерфейса от 10 сентября 2026 года](docs/audit-2026-09-10.md).

Раздел **«Люди»** — список с годами жизни, местами, сведениями о семье и сортировкой по ФИО, рождению или смерти. Неизвестные даты остаются в конце списка. Вместо букв при отсутствии портрета показывается нейтральный силуэт.

Даты можно вводить как **`1.5.1980`**, `01.05.1980`, `1980-05-01`, **`05.1980`** или просто `1980`. Неизвестный день или месяц не подставляется. **«Места»** автоматически находит на карте места рождения и смерти из карточек; исторические названия ищутся по справочникам, исходная запись сохраняется. Подробнее: [карта семьи](docs/places.md).

В карточке уже добавленного человека блок **«Можно уточнить»** предлагает фамилию при рождении, возможного отца по отчеству, возможную мать по известным детям или супруге отца и уточнение брака при общих детях. В форме выбранный отец участвует в поиске матери сразу, до сохранения. Подсказки объясняют основания и не меняют сведения без подтверждения. Сравнение учитывает девичьи и составные фамилии; известные предки, потомки и братья/сёстры не предлагаются как родители.

В хронологии слева — крупные римские обозначения веков, исторические эпохи и тонкие отметки лет. Меню **«Время»** переносит к нужному периоду. Люди без дат остаются отдельно; переходы к векам доступны и до заполнения годов.

Полотно можно тянуть мышью, в том числе за карточку. Обычное нажатие открывает человека, Shift + нажатие выбирает второго для сравнения. Масштаб меняется кнопками, щипком или Ctrl + колесо. По умолчанию открывается **всё древо**. После выбора человека появляется **«Семья выбранного»** для перехода к его ближайшим родственникам. В этом режиме кнопки **«Ещё N»** раскрывают родственников, а **«Всё древо»** возвращает полный обзор. При раскрытии сохраняются масштаб и положение нажатой карточки. Скрытые ветви не оставляют пустых мест. В полном обзоре стрелка на карточке сворачивает потомков. При отдалении карточки упрощаются. [Управление семейным обзором](docs/family-focus.md).

При конфликте версий независимые поля объединяются автоматически. Если одно поле изменено одновременно, окно показывает варианты из архива и черновика; можно выбрать вариант или вернуться к форме. Подробности: [полотно и управление связями](docs/tree-workspace.md).

Люди без даты рождения располагаются в отдельной области над шкалой эпох; после уточнения даты карточка перемещается к своему году. Форма предлагает пол по ФИО, вероятного отца или уже записанных детей — по отчеству и датам, фамилию при рождении — по указанному отцу. Родство и фамилия сохраняются только после подтверждения; пол можно поправить вручную. Старые карточки с неизвестным полом тоже получают названия родства по ФИО без массовой перезаписи базы. [Как работают подсказки](docs/name-hints.md).

Админская панель открывается по адресу **`/admin`**. В разделе **«Доступ и древо»** можно перевернуть направление времени: предки сверху или младшие поколения сверху. В **«Данных и копиях»** доступны скачивание и импорт бэкапа SQLite или `.tar.gz` с фото, изменение названия и импорт JSON. Импорт бэкапа сначала показывает состав и требует подтверждения; перед заменой создаётся копия текущей базы. Аккаунты, роли и настройки доступа остаются действующими. [Подробности восстановления](docs/backup.md).

## Возможности

- Прокрутка по времени, века и эпохи слева; масштабирование, перемещение, поиск людей.
- ФИО, фамилия при рождении, даты и места рождения/смерти, биография, источники; быстрое добавление без обязательной даты рождения.
- Кровное родство, родные, единокровные, единоутробные и сводные братья/сёстры; двоюродные и более дальние родственники.
- Свекровь, свёкор, тесть, тёща, деверь, золовка, шурин, свояченица, зять, невестка, сноха, свояки, сваты; дядя и тётя по браку.
- Явные связи усыновления, крещения, опеки, вскармливания и названого братства. Кумовство и молочное родство выводятся из таких записей.
- Галерея JPEG, PNG, WebP и GIF, до 20 МБ на снимок. Несколько отметок на фотографии, переходы к людям, отдельный портрет.
- Вход только через Яндекс: первый участник — администратор, остальные — читатели. Администратор назначает роли; родственники добавляют и редактируют только свои карточки и фотографии.
- Админка с отдельной публичностью древа и альбомов, резервной копией SQLite и полным бэкапом базы вместе с фото.
- Защита от перезаписи изменений другой вкладки, транзакции и последние 50 версий данных в базе.

## Структура

```text
src/
  main.tsx                 # Вход в приложение
  App.tsx                  # Оболочка, разделы и открытие редакторов
  components/              # Карточки, сравнение, редакторы, галерея, вход
  components/tree/         # React Flow, карточки, связи, эпохи и Worker
  hooks/                   # Выбор людей, AJAX, отмена и конфликты
  domain/                  # Модель, даты, родство, проверки, изменения графа
  server/                  # HTTP API, SQLite, авторизация, фото, бэкап
  styles/                  # Оформление приложения
public/                    # Иконки, логотип, модели, пустой стартовый архив
tests/                     # Проверки родства, базы, авторизации и API
ops/                       # Nginx, systemd и сценарии установки/деплоя
docs/                      # Документация на русском
.github/workflows/         # Проверки и деплой через GitHub Actions
data/                      # Локальная SQLite и uploads; не хранится в Git
dist/                      # Результат сборки интерфейса; не хранится в Git
```

## Проверки

```sh
npm run typecheck
npm run lint
npm test
npm run build
```

Тесты используют временные базы и не меняют рабочий архив. Проверяются направления родства, неполные сведения, дополнительные связи, сохранность фотографий и отметок, конфликт версий, вход и скачивание согласованного бэкапа.

## Сервер и резервные копии

Сайт: **https://drevo.kiiko.ru**. GitHub Actions запускает проверки и деплой при обновлении `main`, используя секрет `DEPLOY_SSH_KEY`. SQLite и снимки хранятся в `/var/www/drevo.kiiko.ru/shared`, отдельно от релизов.

Администратору доступно **«Управление»**: участники, роли, отдельные переключатели публичного просмотра древа и фотоальбомов. Там же — **«Скачать базу SQLite»** и **«Скачать базу и фото»**. Полная копия `.tar.gz` содержит `drevo.sqlite` и `uploads/`. База включает пользователей и настройки доступа; секрет приложения Яндекса хранится отдельно на сервере.
