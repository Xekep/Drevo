Семейный архив с генеалогическим графом, исторической шкалой, русскими названиями родства и фотографиями с отметками людей.

**React + TypeScript · Node.js · SQLite · Vite.** Интерфейс собирается в статические файлы, данные загружаются и сохраняются через AJAX. База и фотографии находятся на вашем компьютере или на вашем сервере.

## Запуск на компьютере

Нужен Node.js **22.13 или новее**; на сервере и в CI используется 22.23.2.

```powershell
cd C:\Users\Xekep\Documents\GitHub\Drevo
npm ci
npm run dev
```

Откройте **http://127.0.0.1:3000**. Локальный сервер слушает только этот компьютер, вход не требуется. При первом запуске создаётся `data/drevo.sqlite` с демонстрационной семьёй: 22 вымышленных человека. Последующие запуски сохраняют ваши данные.

Локальный и серверный архивы независимы. Для переноса данных используйте бэкап или экспорт/импорт JSON и отдельно переносите `uploads/` с фотографиями.

Для запуска собранной версии:

```sh
npm run build
npm start
```

## Как вести семейный архив

1. Нажмите **«Человек»** и заполните карточку. Дата может быть точной (`1950-05-12`) или только годом (`1950`). Источники добавляются в этой же форме.
2. Нажмите **«Связать людей»**, выберите два узла древа и укажите связь. Можно также выбрать людей из списка. Для родителя направление идёт **от родителя к ребёнку**.
3. Откройте карточку и нажмите **«Редактировать»**, чтобы изменить сведения или убрать прямую связь. Признак «Все кровные родители известны» помогает отличать неполнородное родство от неполных данных.
4. Выберите **«Сравнить родство»** и два имени. Панель покажет, кем каждый приходится другому, и цепочку связи.
5. Откройте **«Фотографии» → «Добавить фото»**. На снимке нажмите **«Отметить человека»**, обведите его рамкой и выберите имя. Нажатие на отметку открывает карточку человека. Рамку можно настроить ползунками без мыши.
6. Портрет карточки выбирается отдельно при редактировании человека: из галереи или по ссылке. Все снимки, на которых человек отмечен, появляются в его карточке.

В **«Настройках»** можно изменить название архива, импортировать JSON или начать пустое древо вместо демонстрационного. Перед заменой данных скачайте бэкап.

## Возможности

- Прокрутка по времени, века и эпохи слева; масштабирование, перемещение, поиск людей.
- ФИО, девичья фамилия, даты и места рождения/смерти, биография, источники.
- Кровное родство, родные, единокровные, единоутробные и сводные братья/сёстры; двоюродные и более дальние родственники.
- Свекровь, свёкор, тесть, тёща, деверь, золовка, шурин, свояченица, зять, невестка, сноха, свояки, сваты; дядя и тётя по браку.
- Явные связи усыновления, крещения, опеки, вскармливания и названого братства. Кумовство и молочное родство выводятся из таких записей.
- Галерея JPEG, PNG, WebP и GIF, до 20 МБ на снимок. Несколько отметок на фотографии, переходы к людям, отдельный портрет.
- Вход на сервере, редактирование после входа, скачивание резервной копии SQLite, экспорт и импорт JSON.
- Защита от перезаписи изменений другой вкладки, транзакции и последние 50 версий данных в базе.

## Структура

```text
src/
  main.tsx                 # Вход в приложение
  App.tsx                  # Состояние экрана и граф
  components/              # Карточки, сравнение, редакторы, галерея, вход
  hooks/useArchive.ts      # AJAX, загрузка и сохранение
  domain/                  # Модель, даты, родство, проверки, изменения графа
  server/                  # HTTP API, SQLite, авторизация, фото, бэкап
  styles/                  # Оформление приложения
public/                    # Иконки, логотип, демонстрационные данные
tests/                     # Проверки родства, базы, авторизации и API
ops/                       # Nginx, systemd и сценарии установки/деплоя
docs/                      # Документация на русском
.github/workflows/         # Проверки и деплой через GitHub Actions
data/                      # Локальная SQLite и uploads; не хранится в Git
dist/                      # Результат сборки интерфейса; не хранится в Git
```

## Проверки

```sh
npm run typecheck
npm run lint
npm test
npm run build
```

Тесты используют временные базы и не меняют рабочий архив. Проверяются направления родства, неполные сведения, дополнительные связи, сохранность фотографий и отметок, конфликт версий, вход и скачивание согласованного бэкапа.

## Сервер и резервные копии

Сайт: **https://drevo.kiiko.ru**. GitHub Actions запускает проверки и деплой при обновлении `main`, используя секрет `DEPLOY_SSH_KEY`. SQLite и снимки хранятся в `/var/www/drevo.kiiko.ru/shared`, отдельно от релизов.

После входа доступна кнопка **«Бэкап базы»**. Она скачивает файл `.sqlite`, включая людей, связи, описания фотографий и отметки. **Сами изображения находятся в `uploads/` и в этот файл не входят.** Полное восстановление описано в документации.
