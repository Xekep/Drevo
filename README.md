# Древо

Лаконичный семейный архив: генеалогический граф на вертикальной шкале времени, карточки людей и анализ родства. Русскоязычный интерфейс, адаптивная вёрстка, светлая архивная палитра. В примере — 22 вымышленных человека и 7 поколений.

## Запуск

Node.js 22.13+ и npm. Команды работают в PowerShell, macOS и Linux.

```sh
npm install
npm run dev
```

Страница доступна по адресу, который покажет сервер (обычно http://localhost:3000).

## Статический сайт + AJAX

Вся работа с архивом выполняется в браузере. Данные загружаются запросом `fetch('/data/family.json')`. База данных и прикладной сервер не нужны.

```sh
npm run build:static
npm run preview:static
```

Каталог `dist-static/` можно целиком разместить в корне обычного статического хостинга (Nginx, Apache, Pages). В нём HTML, JavaScript, CSS, JSON, документы и изображения. Для разработки только статической версии: `npm run dev:static`.

`npm run build` отдельно создаёт совместимую с Sites/Cloudflare Workers сборку в `dist/`; она использует тот же интерфейс. Настройки Sites находятся в `.openai/hosting.json`.

## Возможности

- Карточки расположены по году рождения. Вертикальная прокрутка и перетаскивание пустой области перемещают граф; слева закреплена шкала веков и эпох.
- Сплошные линии связывают родителей и детей, пунктирные — супругов. Полоса жизни выбранного человека показывает период от рождения до смерти или текущего года.
- Клик открывает справа ФИО, точные даты, места, занятие, биографию, родственников и источники. Если указан `photo`, отображается фото; иначе — инициалы. Ошибка загрузки фото также заменяется инициалами.
- «Сравнить родство» или Shift/Ctrl/Cmd + клик позволяют выбрать двух людей. Выбранная цепочка подсвечивается. Поддерживаются предки и потомки, братья и сёстры, дяди и тёти, двоюродные и более дальние родственники, супруги, связи через семью.
- Поиск по ФИО, девичьей фамилии, месту рождения/смерти и годам жизни. `/` фокусирует поиск, Enter открывает первый результат, Escape закрывает поиск или карточку.
- Список людей, масштаб 45–135%, вписывание по ширине, переходы по векам и справка. На узких экранах карточка открывается поверх графа.

## Собственные данные

Редактируйте `public/data/family.json`: `title`, `description`, `demo` и массив `people`. Установите `demo: false` для своего архива. Все идентификаторы должны быть уникальными. Ссылки на родителей и супругов должны указывать на существующие записи. Неизвестных родственников не добавляйте в соответствующие массивы.

```json
{
  "id": "anna",
  "surname": "Соколова",
  "name": "Анна",
  "patronymic": "Ивановна",
  "sex": "f",
  "birth": "1930-03-12",
  "death": "2010-09-18",
  "birthPlace": "Тверь, СССР",
  "deathPlace": "Москва, Россия",
  "maidenName": "Иванова",
  "occupation": "Учительница",
  "biography": "История человека…",
  "photo": "/photos/anna.jpg",
  "parents": [],
  "spouses": [],
  "generation": 1,
  "column": 0,
  "sources": [
    {
      "title": "Название документа",
      "type": "Архивная запись",
      "reference": "Фонд, опись, дело, лист",
      "url": "https://example.org/document",
      "note": "Пояснение к источнику"
    }
  ]
}
```

Необязательные поля: `death`, `deathPlace`, `maidenName`, `occupation`, `biography`, `photo`; у источника — `url` и `note`. Пустое отчество допустимо. Даты — `YYYY-MM-DD`; если человек жив, не указывайте `death`. Фотографии положите в `public/photos/`, документы — в `public/archive/`. Источники в демо явно обозначены как вымышленные примеры.

`generation` задаёт подпись поколения, `column` — горизонтальную позицию; допускаются дробные значения для центрирования детей. Вертикальная позиция рассчитывается из даты рождения. Диапазон демо 1830–2035 и масштаб времени задаются `START_YEAR`, `END_YEAR`, `YEAR_HEIGHT` в `lib/genealogy.ts`. Для более ранних данных расширьте диапазон и список эпох `ERAS`. Это редактор исходных данных: добавление людей через интерфейс пока не предусмотрено.

## Проверки

### Подробные названия родства

Панель сравнения показывает две направленные подписи: кем первый человек приходится второму и наоборот, с простым пояснением. Например: «Мария — свекровь Елизаветы», «Елизавета — невестка Марии».

Поддерживаются свекровь, свёкор, тёща, тесть, деверь, шурин, золовка, свояченица, зять, невестка/сноха, свояк, сват/сватья; родные, единокровные, единоутробные и сводные братья/сёстры; отчим, мачеха, пасынок, падчерица; дяди, тёти, племянники, двоюродное и более дальнее родство. У редких названий есть расшифровка, для сложных отношений — точная цепочка.

В `parents` подразумеваются кровные родители. Два указанных родителя по умолчанию считаются полным списком. Необязательное `parentageComplete: false` явно помечает сведения как неполные. `parentageComplete: true` подтверждает полноту списка, когда записей меньше двух. При неполных сведениях приложение использует осторожные подписи вроде «брат по отцу» или «муж матери», а не утверждает неполнородность или сводное родство. Сводные родственники не имеют общих родителей; неполнородные имеют одного общего родителя. Модель `spouses` описывает указанные в архиве браки без дат и статусов разводов; автоматическая оценка отношений на конкретную историческую дату не выполняется.

Термины сверены со [справочником Грамоты](https://gramota.ru/biblioteka/spravochniki/slovar-spravochnik-neprostye-slova/terminy-rodstva) и [разбором родства и свойства](https://gramota.ru/journal/stati/zhizn-yazyka/terminy-rodstva-i-svoystva-v-russkom-yazyke). «Сродный» означает родственный, не самостоятельную степень; алгоритм показывает конкретное название.

### Запуск проверок

```sh
npm test
npm run typecheck
npm run lint
npm run build:static
npm run build
```

Тесты проверяют направления родства, общих предков, неполнородных родственников, цепочки через брак и общего ребёнка, повторяющихся предков, возраст и валидацию данных. Отсутствие пути означает недостаток сведений, а не доказанное отсутствие родства. Названия брачных связей вычисляются только по явным записям `spouses`.

## Структура

- `app/drevo.tsx` — интерфейс, AJAX, управление графом и панели.
- `app/globals.css` — стили и адаптивность.
- `lib/genealogy.ts` — типы, валидация, координаты, даты и расчёт родства.
- `public/data/family.json` — семейный архив.
- `public/archive/` — демонстрационные источники.
- `public/og.png` — обложка для предпросмотра ссылок.
- `vite.static.config.ts`, `index.html`, `app/static-entry.tsx` — автономная статическая сборка.

При размещении статической сборки на собственном домене замените в `index.html` абсолютные `og:image` и `twitter:image` на `https://ваш-домен/og.png`. Для Sites они уже указывают на адрес проекта.
