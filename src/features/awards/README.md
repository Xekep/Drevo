# Каталог наград

Каталог отделён от семейного факта. `AwardDefinition` описывает саму награду, её страну, тип, степени, алиасы и изображение; `PersonAward` хранит то, что относится к конкретному человеку: введённое название, год, источник и стабильную ссылку `awardDefinitionId`.

Автосопоставление не меняет пользовательское название. Строка нормализуется: регистр, `ё/е`, кавычки, разные тире, пробелы, варианты `30-летия`/`30 лет`, а также префиксы `медаль`, `юбилейная медаль`, `орден` и `знак отличия`. Ссылка на каталог создаётся только при единственном совпадении. Старые записи без `awardDefinitionId` распознаются при отображении, поэтому миграция данных не требуется.

Сейчас каталог включает государственные военные, трудовые и юбилейные награды СССР, основные государственные награды России, часть ведомственных наград атомной отрасли и иностранные награды, которыми могли награждаться советские граждане: Монголия/МНР, Польша/ПНР, Чехословакия и ГДР. В частности поддерживается медаль МНР «30 лет Халхин-Гольской Победы» и распространённые варианты её написания.

Изображение добавляется только вместе с источником и лицензией. Если проверенного изображения пока нет, интерфейс показывает стандартную пиктограмму и не пытается угадывать внешний вид награды. Проверенные изображения и их лицензии перечислены в `IMAGE_SOURCES.md`.
