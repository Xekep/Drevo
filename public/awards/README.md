# Локальные изображения наград

Изображения наград в профиле человека должны быть локальными PNG с прозрачным фоном. Самодельные SVG-реконструкции для наград не используются.

Структура каталогов отражает систему наград, а не язык названия:

- `ussr/` — государственные награды СССР;
- `ru/` — награды современной Российской Федерации;
- `ru/rosatom/` — ведомственные знаки Госкорпорации «Росатом»;
- `mn/` — Монголия / Монгольская Народная Республика;
- для других государств создаётся отдельный каталог по стабильному коду системы.

Нельзя переиспользовать один визуальный файл для двух наград разных государств только из-за одинакового или похожего названия. Связь выполняется через `awardDefinitionId` в `src/features/awards/catalog/visuals.ts`.

Исходники расширенного каталога, авторы и лицензии перечислены в `src/features/awards/catalog/image-sources.json`. Его PNG хранятся в репозитории; восстановить их из Wikimedia Commons можно командой `node ops/fetch-catalog-award-images.mjs --force`. Скрипт удаляет только связанный с краем светлый фон и не перерисовывает награду. Старые восемь ассетов по-прежнему подготавливаются `ops/fetch-award-images.sh` перед сборкой.

Производные PNG распространяются на условиях лицензий исходных файлов, указанных в манифесте; лицензия кода проекта к ним не применяется. При использовании изображения указывайте автора, страницу исходника и соответствующую лицензию.

Позиции без достоверного изображения показывают нейтральный значок медали. Лента, удостоверение или награда другой степени не используются как подмена. Источник и лицензия конкретного изображения доступны в раскрытой карточке награды.
