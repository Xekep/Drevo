# Разработка «Древа»

- Интерфейс, README и документация — на русском; исходники приложения — в `src/`, проверки — в `tests/`.
- `App.tsx` связывает разделы и окна. Камеру, геометрию и жесты держите в `components/tree/`, выбор людей — в `hooks/useWorkspaceSelection.ts`. Не подписывайте оболочку и формы на движение камеры.
- `domain/` содержит чистые функции без React, HTTP, браузера и SQLite. Адаптер связей — `connections.ts`, геометрия — `tree-layout.ts`, изменения полей — `changes.ts`, вычисление родства — `kinship.ts`.
- Объекты React Flow не заменяют семейные данные. Не записывайте предполагаемые даты, родителей и фамилии ради раскладки.
- Не создавайте Canvas размером со весь архив. Геометрию считайте в Worker, передавая только нужные поля; отделяйте измерения вычислений от браузерного FPS и памяти.
- Создание, перенос конца и смена типа связи сохраняются одним запросом через `domain`. Сервер независимо проверяет даты, циклы, дубликаты, роль и авторство.
- Отмена возвращает конкретные изменения текущей вкладки. При конфликте сохраняйте черновик, объединяйте только независимые поля, показывайте варианты для совпавших. Не подставляйте новую `revision` под устаревший полный снимок.
- Сохраняйте сценарии без перетаскивания, управление клавиатурой, мобильную панель и уменьшенную анимацию.
- Перед завершением: `npm run typecheck`, `npm run lint`, `npm test`, `npm run build`, затем `npm run test:worker`. Последний шаг проверяет именно собранный Worker с ELK. Для изменений графа, прав, отмены и конфликтов нужны содержательные тесты. Рабочую базу не используйте для тестов.
- Деплой проходит через workflow с бэкапом и отдельными релизами. Не заменяйте рабочую SQLite и фотографии стартовыми данными.
- Не коммитьте секреты, `.env`, базы, пользовательские фото, `node_modules`, модели и `dist`. Не меняйте OAuth и роли ради проверки интерфейса.
- В отчёте различайте автотесты, сборку и фактическую проверку браузером. Если браузер недоступен, укажите ограничение.

См. [архитектуру](docs/architecture.md), [полотно и отмену](docs/tree-workspace.md), [деплой](docs/deployment.md).
